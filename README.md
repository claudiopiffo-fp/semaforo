# Semaforo Interattivo

Semplice applicazione web a pagina singola che simula un semaforo luminoso con modalità **Automatica** e **Manuale**.

## Funzionalità
- **Modalità Automatica:** ciclo continuo tra Rosso, Verde e Giallo con durate modificabili in tempo reale.
- **Gestione Giallo:** impostando il Giallo a `0`, viene automaticamente escluso dal ciclo.
- **Modalità Manuale:** avanzamento manuale tramite pressione di un qualsiasi tasto della tastiera, clic del mouse o tap su schermo.

## Pubblicazione su GitHub Pages
1. Crea un nuovo repository pubblico su GitHub.
2. Carica i file `index.html` e `README.md` nella root del repository.
3. Vai su **Settings** > **Pages**.
4. Sotto **Build and deployment** > **Source**, seleziona **Deploy from a branch**.
5. Seleziona il branch `main` e la cartella `/ (root)`, poi clicca su **Save**.
6. Dopo circa 1 minuto il sito sarà online all'indirizzo `https://<tuo-username>.github.io/<nome-repository>/`.
